# Cuber

Petit module Maya d'exemple pour le TP4 du cours NAND403. Il ajoute un shelf Cuber avec un bouton qui ouvre une fenêtre PySide6 permettant de créer un cube (polyCube).

## Installation

1. Copie ballanimation.mod et le dossier cuber dans le dossier modules de Maya, côte à côte : C:\Users\<nom>\Documents\maya\modules
- Note : Si le dossier modules n'existe pas, crée-le.

2. Redémarre Maya complètement. Un onglet Cuber apparaît dans le shelf.

## Utilisation

Clique sur l'onglet Cuber du shelf, puis sur le bouton Cuber.
Dans la fenêtre, clique sur Create cube pour créer un cube dans la scène.
